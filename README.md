# Проектная работа «Оно тебе надо»

## Назначение

Проект представляет собой статическую страницу аукциона вещей, в которые никто не верил. Вёрстка выполнена по макету проектной работы и включает шапку, обложку, список лотов, раздел с описанием аукциона и подвал.

## Структура проекта

- `index.html` — разметка страницы и её текстовое содержание.
- `styles/global.css` — общие правила, сброс стандартных отступов и базовые настройки элементов.
- `styles/style.css` — стили секций, типографики, фоновых изображений и расположения элементов.
- `fonts/fonts.css` — подключение локальных начертаний шрифта Raleway.
- `fonts/` — файлы шрифта Raleway в форматах WOFF2 и WOFF.
- `images/` — фоновые изображения, логотипы и значки социальных сетей.

## Реализация

Структура страницы размечена семантическими элементами HTML: `header`, `main`, `section`, `nav` и `footer`. Для лотов применены список `ul` и карточки `article`. Адрес оформлен элементом `address`.

Для размещения элементов шапки и блока «Об аукционе» используется CSS Grid. Меню, карточки лотов и группы содержимого размещаются с помощью Flexbox. Класс `overlay` задаёт полупрозрачное затемнение обложки и карточек.

Страница оформлена средствами HTML и CSS без сценариев JavaScript. Кнопка «Сделать ставку» отображается как элемент интерфейса; обработчик действия в проекте не реализован.

## Просмотр страницы

Откройте файл `index.html` в браузере. Ресурсы подключены относительными путями, поэтому запуск локального сервера не требуется. В базовых стилях задана минимальная ширина страницы 1100 пикселей.
